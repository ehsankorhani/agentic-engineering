## 🌟 Course Overview

> *"The best way to predict the future of software engineering is to build it — with agents."*

**Agentic Engineering** is the discipline of designing, orchestrating, and operating **AI agents** that plan, write, review, test, and ship software — with humans as *directors* rather than *typists*. This course is a hands-on journey from first principles to production-grade, agent-powered delivery systems.

Instead of asking *"how do I write this code?"*, you'll learn to ask:

- 🧠 **How do I decompose this problem** into agent-suitable tasks?
- 🔁 **How do I design workflows** where agents collaborate reliably?
- 🛡️ **How do I add guardrails** so autonomous output is safe, verified, and reviewable?
- 📈 **How do I scale** from a single agent to a full **Software Factory**?

## 🗺️ High-Level Context

Software engineering is shifting from **writing code by hand** to **directing systems that write code**.

```
  Traditional SDLC                    Agentic SDLC
 ┌──────────────┐                 ┌──────────────────┐
 │ Human writes │                 │ Human defines    │
 │ every line   │      ──►        │ intent + specs   │
 │ of code      │                 │ + quality gates  │
 └──────────────┘                 └───────┬──────────┘
                                          ▼
                                  ┌──────────────────┐
                                  │ Agent workflows  │
                                  │ plan · build ·   │
                                  │ test · review    │
                                  └──────────────────┘
```

**The core insight:** LLMs are probabilistic, but software delivery demands deterministic outcomes. Agentic Engineering is the craft of wrapping non-deterministic intelligence in **deterministic scaffolds** — workflows, contracts, tests, and review gates — so that autonomous output becomes trustworthy.

This course covers the **concepts, patterns, and practice** of that craft:

| Pillar | Focus |
|---|---|
| 🧠 **Mindset** | From "coder" to "orchestrator" — thinking in systems and specs |
| 🏗️ **Architecture** | Agent roles, tool design, context engineering, memory |
| 🔁 **Process** | AWD: designing workflows, handoffs, and feedback loops |
| ✅ **Quality** | Verification-first development, guardrails, human-in-the-loop gates |
| 🚀 **Operations** | The Software Factory: end-to-end agentic delivery pipelines |
